# Comisioane pentru conturi

| Cont | Administrare |
|---|---:|
| Galaxy Start | 0 RON/lună |
| Galaxy Plus | 12 RON/lună |
| Galaxy Premium | 35 RON/lună |
| Galaxy Savings | 0 RON/lună |
| Galaxy Flex | 0 RON/lună |

## Interpretare

Comisionul de administrare este lunar. El nu include automat comisioanele unor operațiuni distincte, precum anumite transferuri sau retrageri de numerar.

## Exemplu

Un client cu Galaxy Plus plătește 12 RON/lună pentru administrare, iar un transfer extern online poate genera separat comisionul de 2,50 RON.
